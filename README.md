## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/OlgaZaglavnova/Tellsy_test2024.git
```

Navigate to the project folder:

```bash
cd Tellsy_test2024
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open the application:

```
http://localhost:4200/
```
